# MicroKey8
An 8 key rhythm game controller that uses microswitches commonly found in mice for short travel and advanced debounce logic.

The 3keyFullAlt branch is designed as a replacement to the "Alternate" mode for osu lazer. That mod ignores any inputs that aren't alternating between z and x.
That mod isn't compatible with the 3key playstyle because it 3key is techically zxz zxz. This version of the firmware ignores any inputs that aren't in "asdasd" order, as if a 3key alternate mod existed.
